Smart Home Automation System
This project implements a complete smart home automation system using two Arduino Uno boards communicating through the I2C protocol.

System Modules
Smart Door Lock
  Password-based authentication using a 4x4 keypad.
  Servo motor used for door locking and unlocking.
Window Security System
  MC-38 magnetic reed switch for window monitoring.
  Buzzer alarm for intrusion detection.
  Arm/Disarm security mode.
Exterior Lighting System
  HC-SR04 ultrasonic sensor for motion detection.
  Automatic porch light control.
Interior Lighting System
  LDR-based light sensing.
  Automatic indoor lighting.
  Manual override using a push button.
Climate Control System
  DHT11 temperature sensor.
  Automatic fan activation when temperature exceeds the threshold.
Communication System
  Arduino A works as I2C Master.
  Arduino B works as I2C Slave.
  Real-time data exchange between the two boards.
